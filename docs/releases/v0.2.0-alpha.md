# Pontis v0.2.0-alpha

**这仍然是 alpha。** 本版本在 `v0.1.0-alpha.2` 之后合入了 OIDC 单点登录与配对码、浏览器浏览统计分析与专注度指标，并完成了全仓库深度代码审查（R13–R50 及工程卫生项）的系统性修复与加固。由于部分高风险场景仍需持续的真实浏览器/多 Profile 长稳验收，本标签仍标记为 `alpha` 预发布。

代码里的基础版本已升级为 `0.2.0`，「`alpha`」存在于该 SemVer 预发布 tag（`v0.2.0-alpha`）中，原因同样是浏览器扩展 `manifest.json` 的 `version` 仅接受点分数字。

| 项 | 值 |
| --- | --- |
| Server 版本 | 0.2.0 |
| HTTP API 版本 | v1 |
| 同步协议版本 | 1 |
| 数据库 schema 版本 | 27 |
| 扩展版本 | 0.2.0（两个包同为该版本） |

## 相对 v0.1.0-alpha.2 的主要变化

### 认证、单点登录与账号安全
- 新增 OIDC 单点登录与设备配对码登录流程，支持无密码 SSO 账号开通与管理。
- 修复 OIDC 回调 state cookie 常数时间校验，防止登录 CSRF（R25）。
- 引入 `email_verified_at` 验证门控，禁止未验证邮箱自动关联本地账号（R26）。
- 为公开认证接口增加 `application/json` 强制校验、同源/扩展 Origin 校验与全站 CSP 安全响应头（R27），将管理员路由集中至独立鉴权中间件组（R23）。
- 原子化首次初始化建号与管理员防降级校验，限制 Argon2 并发并消除账号存在性计时侧信道（R28）。

### 对账引擎、同步与扩展健壮性
- 修复同父目录书签向后移动 off-by-one（R13），全面支持空标题书签端到端同步与展示（R14）。
- 修复 Full Resync、Mapping-lost Recovery、歧义目录递归匹配与空决定收敛（R29–R31, R33–R34）。
- 支持对账期间本地删除/改名捕获与孤儿创建节点采纳，在写事务内复核 session 状态并统一接入 `changesets` 活动流与过期工件清理（R32, R35–R37, R43）。
- 实现目录删除与并发新建的对称保护及 `Recovered` 可见目录投影（R15）、异常回执可见化（R16）、部分模式拖入/拖出挂载目录处理（R17）、周期 Alarm 保活（R18）、Full 模式多根槽校验（R19）、取消跨设备 URL 错配（R20）与运行锁续期（R24）。

### 导入导出、撤销、广场与空间清理
- 修复 Netscape HTML 实体解码、空文件夹 `<DL>` 对齐、按根槽完整导出子树与多根槽导出/导入（R38–R39, R41）。
- 撤销 `CREATE` 时检查后续修改/移动进入人工确认、撤销本身支持再撤销（重做），修正 `MOVE` 成环检查与 `DELETE` 原位恢复（R40），恢复备份后 `ListChangeSets` 优先展示当前 epoch（R44）。
- 广场 Replace 报告删除数、子树发布 Replace 仅替换目标发布节点，支持快照更新换源与防空树误覆写（R42, R45）。
- 删除空空间/设备时级联清理历史与对账残留，设备端跨空间搬运强制校验双端活跃绑定。

### 任务系统、备份保留与服务端加固
- 新增迁移 `000027_jobs_type_unrestricted.sql` 移除 `jobs.type` 硬编码枚举约束使 `activity.gc` 正常执行，调度器对永久性入队错误执行退避（R46）。
- 支持运行中任务租约定期续期与 `worker_id` fencing（R47）、链接检查边查边落库（R48）、排队任务 CAS 即时取消（R49）、类别并发上限与空间去重及计划配额限制（R50）。
- 新增全局请求体上限、公开认证令牌桶限流、`/sync` 批次操作上限 200（R21），以及 SQLite `_txlock=immediate` 写锁与 WAL 只读连接池分离（R22）。

## 升级提示

**alpha 阶段请务必先备份。** 升级前请复制数据目录（`pontis.db` 与 `backups/`），本版本包含数据库迁移（最高至版本 27），迁移只前进不自动回退。

扩展升级请在原安装目录覆盖文件后点击「重新加载」（不要卸载），并在「设备」页核对安装包 SHA-256 摘要。
